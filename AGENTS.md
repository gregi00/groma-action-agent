## Groma

This project uses Groma. Before scanning, inspecting, or curating architecture,
or changing files for a Backlog task, run `groma agent-instructions` and read
the guide it names for that job. If it reports a first scan, ask whether the
user wants to curate the architecture. Do not edit Groma-owned architecture
files directly; follow the generated guide.
<!-- groma:end -->

## Issue handling

Follow `.github/copilot-instructions.md` when working on GitHub issues. Bug
issues assigned to Copilot should be fixed and delivered in a linked pull
request. Assigning Copilot to a feature issue is approval to implement it;
unassigned feature issues require a proposed implementation summary and
explicit `/implement` approval before code changes begin.
